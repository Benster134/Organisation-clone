# Organisation-clone
Clone a network from one organisation to another

## Getting Started

This repository is set up to host a Visual Studio project.

### Copying your Visual Studio project here

1. **Clone this repository** to your local machine:
   ```
   git clone https://github.com/Benster134/Organisation-clone.git
   ```

2. **Copy your Visual Studio project files** into the cloned repository folder.  
   Your solution (`.sln`) file and project folders should sit at the root of the repository.

3. **Stage and commit** your files:
   ```
   git add .
   git commit -m "Add Visual Studio project"
   ```

4. **Push** to GitHub:
   ```
   git push
   ```

A `.gitignore` for Visual Studio is already included so that build output, local user settings, and other generated files are automatically excluded from version control.
